Curator Frequently Asked Questions

How does the AI Assistant book services for users?

When a traveler asks Afrimax AI on the Trip Planner or website to book a tour (e.g. Serengeti Safari, Ashanti Kente workshop, Nile Cruise), the booking is recorded into Supabase and shows up under AI Bookings. As administrator, you can review, approve, or adjust the status.

How do I store new images and texts for the website?

Navigate to Exhibits & Content or click + Add Exhibit. You can upload an image file directly (or paste an image URL), input the historical synopsis, assign a region and category, and hit Save.

How is authentication separated between Admin and Visitors?

Travelers and public members sign in using Firebase Authentication (Google Sign-In & Email). Administrators authenticate using Supabase with Row Level Security (RLS) policies.
